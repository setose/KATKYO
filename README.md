# KATKYO

家庭教師のアルバイトで作成した、中学・高校生向けの学習教材（解説HTMLページ）をまとめたリポジトリです。

[index.html](index.html) が教材一覧のトップページです。GitHub Pages / Cloudflare Pages で公開すると、そのままこのページから各教材へアクセスできます。

## 構成

```
中学数学/   中学数学の解説ページ
高校数学/   高校数学（2次関数、複素数平面、数IIなど）
高校物理/   高校物理（波動など）
高校古文/   高校古文（動詞の活用など）
```

各フォルダの中に単元ごとのHTMLファイルが入っています。

## 公開方法

- **GitHub Pages**: リポジトリの Settings > Pages で、ブランチを `main`、ルートディレクトリを `/`（root）に設定して公開。
- **Cloudflare Pages**: ビルドコマンドなし、出力ディレクトリを `/`（ルート）に設定してデプロイ。
